How it works

See it work, end to end

Scroll to walk through one real mission — from filing the ticket to the “shipped” notification.

1 Create

You file a ticket

Describe the work in a line — “Build a notes app with an API and UI.” Pick an autonomy level and dispatch. That’s the whole ask.

2 Build

The team builds — live

The PM specs it, the CTO plans it, and engineers build their slices in parallel. Every step streams into the console as it happens.

3 Track

The dashboard updates itself

Missions in flight, agents on shift, spend and tokens — the command center reflects reality in real time, no refresh.

4 Verify

Tickets move as work lands

Each slice is a card. It flows To Do → In Progress → QA → Done as the team codes, reviews, and verifies — with the evidence attached.

5 Ship

Shipped — you’re notified

QA passes, the merge gate clears with your sign-off, and it deploys. You get a notification: the app is live.

Capabilities

Everything a real engineering org needs

Not a chatbot — a company. Providers, skills, memory, integrations, and guardrails, working together.

Intake to shipped

A full AI team takes a ticket through spec, plan, build, code review, QA, and ship — a decision graph, not a straight line.

Parallel, coherent builds

Role-matched engineers build their slices in parallel git worktrees, then merge. Only the failing part rebuilds on rework.

QA that runs the real app

The harness boots the app's own server, drives headless Chromium, and checks each acceptance criterion by behaviour.

Configurable autonomy

Manual, assisted, supervised, or autonomous. Even autonomous can't force-push or auto-approve a risky merge.

Any model — incl. Claude CLI

Bind Anthropic, OpenAI-compatible, local Ollama, or your Claude Code CLI seat per agent, with failover and live metering.

Run the app in one click

Boot any shipped mission on a free localhost port and open it live — real API and UI, not a snapshot.

The team

Ten specialists, one mission each

Each agent owns a role and a model binding, collaborates through a shared ledger and memory, and reports every action.

Autonomy

You decide how much rope

Set a default for the workspace and override per mission. Higher levels ask for fewer confirmations — the guardrails always hold.

Manual

The team proposes every step and waits for you.

Assisted

Drafts spec & code; you approve each phase.

Supervised

Builds & tests autonomously; merge & deploy wait for your sign-off.

Autonomous

Ships end-to-end within the guardrails you set.
